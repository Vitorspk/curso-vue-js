# Vue.js Course - Tutorial and Applications

A comprehensive Vue.js 2 learning repository featuring fundamental concepts and complete application examples demonstrating the power and simplicity of Vue.js framework.

## 📚 About This Repository

This repository contains educational materials and practical examples for learning Vue.js, organized into two main sections:
- **Essentials**: Core Vue.js concepts with simple, focused examples
- **Applications**: Complete, functional applications showcasing real-world Vue.js usage

## 🚀 Quick Start

### Prerequisites
- Basic knowledge of HTML, CSS, and JavaScript
- A modern web browser
- Node.js and npm (for application projects)

### Running the Examples

#### Essentials Section
The examples in the `essentials/` directory can be run directly in your browser:
1. Navigate to any subfolder in `essentials/`
2. Open the `index.html` file in your web browser

#### Applications Section
For the application projects with build systems:

1. Navigate to the application directory:
```bash
cd applications/[app-name]
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

4. Build for production:
```bash
npm run build
```

## 🎯 Essentials - Core Concepts

Each example in the essentials directory focuses on a specific Vue.js concept:

- **Instance**: Creating and configuring Vue instances
- **Components**: Building reusable components
- **Directives**: Using Vue's built-in directives
- **Computed**: Working with computed properties
- **Buttons**: Event handling and methods
- **Lists**: Rendering and manipulating lists
- **Hooks**: Understanding lifecycle hooks

## 🛠️ Applications

### 1. Notemaster
A simple note-taking application featuring:
- Create, read, and delete notes

- Bootstrap styling
- Real-time date tracking

### 2. Starbase
A space-themed application demonstrating:
- Component-based architecture
- Props and data flow
- Custom styling

### 3. Starbase-Router
Enhanced version of Starbase featuring:
- Vue Router integration
- Single Page Application (SPA) navigation
- Route management

### 4. Jokester
A fun joke application showcasing:
- API integration
- Asynchronous data fetching
- User interaction

### 5. Turnout
An event management application with:
- Form handling
- Data validation
- State management

## 🔧 Technologies Used

- **Webpack 3** - Module bundler
- **Babel** - JavaScript transpiler
- **Vue Router** - Official router for Vue.js
- **Bootstrap 3** - CSS framework for responsive design

## 📖 Learning Path

Recommended order for studying this repository:

1. Start with `essentials/instance` to understand Vue basics
2. Progress through other essential concepts
3. Study `notemaster` for a simple complete application
4. Explore more complex applications like `starbase-router` and `turnout`
5. Build your own application using these examples as reference
